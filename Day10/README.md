# Day 10 Mini Project

Overview
--------

This repository contains a short mini-project for Day 10. The main artifact is a Jupyter Notebook that demonstrates the exercises and solutions worked on during the session.

Files
-----

- day_10_mini_project.ipynb — main Jupyter Notebook with exercises and solutions.

Prerequisites
-------------

- Python 3.8+ recommended
- pip
- (Optional) virtual environment tooling: `venv` or `conda`
- Jupyter or VS Code with the Jupyter extension

Setup
-----

1. Create and activate a virtual environment (recommended):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

On macOS / Linux:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. (Optional) Install dependencies if you add any to `requirements.txt`:

```bash
pip install -r requirements.txt
```

Running the notebook
--------------------

- In VS Code: open the workspace and click the `day_10_mini_project.ipynb` file. Ensure the Python kernel is selected (choose the `.venv` interpreter if using a virtualenv).
- Using Jupyter Notebook/Lab from terminal:

```bash
jupyter notebook
# or
jupyter lab
```
